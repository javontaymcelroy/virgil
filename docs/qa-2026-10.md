# QA pass, October 2026

Scope: the whole app on branch `claude/read-aloud-mac-voices` (commit fb08820). Security review
with adversarial tests, accessibility, bugs and missing states, Web Interface Guidelines, and a
design pass over screenshots at three widths. Each item says how it was confirmed so the fix
can be checked against the same test.

**Status: everything below is fixed** in the commit after the tooling one. The confirming
tests now pass as ordinary tests (the `finding()` and `#[ignore]` marks are gone). Two more
bugs turned up while fixing and are fixed in the same commit:

- B13 `src/reader/reader.js` `fillVoices` ran once with an empty list before the bridge
  answered, and wrote that empty pick back to storage, so the saved voice was lost on every
  launch (`states.spec.js › a saved voice pick survives the voice list arriving late`).
- B14 `src/panel.js` opening Settings never moved focus into the drawer: the first candidate
  was the hidden Custom-theme textarea, and focusing it failed silently
  (`keyboard.spec.js › arrow keys inside an open drawer`, `a11y.spec.js › focus rings inside the theme list`).

Two items were resolved differently from the proposal: errors no longer open the Add text
panel, since the status line now sits under the reader where it is always visible; and the
theme list keeps its rounded clipping, with focus rings inside it drawn inward instead.

## How findings were confirmed

- **Rust**: `cargo test -- --ignored` runs the two adversarial tests marked `#[ignore]` with the
  finding id (`src-tauri/src/import/epub.rs`, `src-tauri/src/import/html.rs`). They fail today
  and are the acceptance test for the fix (drop the `#[ignore]` with it).
- **Browser**: `npm run test:e2e` drives the Vite-served UI in WebKit (the app's own engine)
  through a Tauri IPC shim (`tests/e2e/tauri-shim.js`), since `tauri-driver` has no macOS
  build. Tests that confirm an open finding call `finding("A1")`, which marks them expected to
  fail; Playwright reports the moment one starts passing, which is the cue to remove the mark.
  Screenshots for the design pass land in `tests/e2e/__screenshots__/` (gitignored).
- **Review**: read, reasoned about, no test (CI config, lock handling).

## Web Interface Guidelines

Checked `src/index.html`, `src/styles/app.css`, `themes/default/theme.css`, `src/theme.js`.
Where a guideline conflicts with Virgil's own tokens or sentence-case voice, the design system
wins and the conflict is noted.

- `src/styles/app.css:13` - `outline: none` is replaced by a shadow, but the shadow is 25% alpha (see A2).
- `src/styles/app.css:35,53,83,296` - `.brand`, `.panel h2`, `.hint`, `.footnote`: no `text-wrap: balance` / `pretty`; the three-line footnote rags unevenly.
- `src/index.html:35,52` - `#wpmLive`, `#eta`, `#pos`, `#pct` change every word while reading and are not `tabular-nums`, so the labels jitter (G2). `.setting .val`, `.record .num`, `.log .n` have it.
- `src/styles/app.css:171-176` - the drawer animates `width` (layout) rather than `transform`; every frame re-lays-out the reader column. Design choice (docked panel), noted only.
- `src/styles/app.css:150,233` - transitions outside the reduced-motion block (A9).
- `src/index.html:15` - the reader column is a `<div class="wrap">`, no `<main>` landmark; `<header>` and the two `<aside>`s exist.
- `src/index.html:107` - `#input` textarea: no `spellcheck="false"` for pasted prose (minor; red underlines on a book).
- `src/styles/app.css:83` - `.hint` nowrap + ellipsis (B12).
- ✓ `…` not `...` (`index.html:19,107,110,129`), curly quotes in copy, no `transition: all`, `<select>` has explicit color/background, `color-scheme: light dark`, `min-width: 0` on every flex child that needs it, `overscroll-behavior: contain` on scrollers, `type="button"` everywhere, `aria-label` on the icon-only close button, `inert` on closed drawers, hover states on every control, sentence case throughout, empty state for the log, loading ("Opening…") and error states for import, `<html lang>`.
- n/a (desktop Tauri window): `touch-action`, `theme-color` meta, safe-area insets, 16 px input font size for iOS zoom.

## Proposed fixes (pick any)

Smallest change that closes each item, each landing with its confirming test:

- **S1** per-chapter and total decompressed caps in `epub.rs` (20 MB / 200 MB), error "This EPUB is too large to open." **S2** lowercase once per chapter in `html.rs`. **S3** reject `_` in `replacing`; error on a duplicate `add_theme` slug; `save_override` only for known ids. **S4** secrets in the signing step's `env:` only, `ref_name` through `env`, actions by SHA. **S5** cap text at 20k chars. **S6** `lock().unwrap_or_else(|e| e.into_inner())`. **S7** keep, show the B3 message.
- **A1** skip the global keys when the target is a button, checkbox, select, input or an open drawer; keep ↑/↓ native on `#wpm` and ←/→ native on `#scrub`. **A2** 2 px solid accent ring (≥3:1), `outline-offset` and padding instead of `overflow: hidden`. **A3** `aria-live="polite"` on `#hint`; a status line under the stage so `#status` is visible and announced with the panel closed; set text after `inert` is cleared. **A4** `aria-valuetext` "Word N of M"; `aria-labelledby` for Pace. **A5** words as `<button tabindex="-1">`; Enter on `#stage`. **A6** `aria-label="Confirm delete X"`. **A7** `--text-faint` ≥ 4.5:1 both schemes. **A8** 24 px fill-switch. **A9** extend the reduced-motion block; gate `scrollTo` behaviour. **A10** `inert` on `.wrap` while the drawer overlays (<980 px) plus a scrim. **A11** `aria-keyshortcuts` on play/back/fwd.
- **B1** watchdog in the speech pacer (3 s + 0.5 s per 100 chars) → "The system voice didn't start. Try another voice." **B2** any seek while stopped resets to "Read" / "Paused.". **B3** "Too long to keep between launches; open it again next time." **B4** covered by A3. **B5** restart the current position with the new pacer or voice. **B6** disabled select with "No voices installed" + the note. **B7** `liveWpm` returns `min(wpm, BASE_WPM × 4)`; ETA uses it. **B8** re-check `playing` after the await. **B9** also close a chunk past 2×`maxWords`. **B10** restart speech on `change` (and on `input` after 150 ms idle); cache `prime()` by token identity. **B11** `.catch` that reports via status. **B12** two-line hint.
- **G2** `tabular-nums` on the stage and scrub labels. **D1** fixed-width action column. **D2** with A10. **D3** placeholder "Name" or none. **D4** move "Restore sample" to its own line or make it a bordered button.
